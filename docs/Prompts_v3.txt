Prompt 13：Research Reviewer（Evidence）

你的任務不是評論設計。

而是驗證所有結論是否具有 Evidence。

將所有結論分類：

- Confirmed — 已有充分證據支持。
- Likely — 有合理推論，但缺乏驗證。
- Hypothesis — 純屬假設。
- Requires Prototype — 必須透過 Prototype 驗證。
- Requires User Interview — 必須透過真實使用者驗證。
- Requires Benchmark — 必須透過 Benchmark 驗證。

請不要提出新的設計，
只驗證目前所有假設是否可信。

Prompt 15：Consensus Reviewer（共識整理）

你是一位 Architecture Review Chair。

你已閱讀所有 Reviewer 的意見。

請不要提出新的觀點。

你的任務是整理 Consensus。

將所有結論整理成：

- Consensus — 所有 Reviewer 都同意的地方。
- Major Disagreement — Reviewer 之間存在重大分歧。
- High Risk — 即使存在分歧，也應優先處理的高風險問題。
- Prototype Required — 不應繼續討論，而應立即建立 Prototype。
- User Validation Required — 必須透過真正使用者驗證。

Final Recommendation：

請回答：

- 是否批准開始開發（YES / NO）
- 若 YES，開始前最重要三項修改
- 若 NO，真正原因是什麼
